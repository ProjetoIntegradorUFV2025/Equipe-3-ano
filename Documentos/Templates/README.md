# Pasta Templates

A pasta **Templates** reúne todos os **modelos de documentos, padrões e diretrizes** utilizados no projeto **(Des)conecta**.  
Seu objetivo é padronizar a documentação e fornecer materiais de referência para toda a equipe, garantindo **consistência**, **clareza** e **organização** ao longo do desenvolvimento.

---

## 📂 Conteúdo

Os arquivos aqui podem incluir:

- **Modelos de Documentos** – Estruturas pré-definidas para atas, relatórios, planos, entre outros.  
- **Padrões de Escrita** – Convenções de nomenclatura, formatação e estilo de documentação.  
- **Diretrizes de Projeto** – Boas práticas e recomendações a serem seguidas pela equipe.
