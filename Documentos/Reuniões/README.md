# Pasta Reuniões - Registro das Reuniões por Sprint

Esta pasta centraliza os **links e registros das reuniões** realizadas durante o desenvolvimento do projeto **(Des)conecta**. Os materiais estão organizados por sprint para facilitar o acesso e acompanhamento das discussões de cada fase do projeto.

## 🗂️ Organização por Sprint

As reuniões estão organizadas conforme as sprints do desenvolvimento:

- **`Sprint01/`** - Links e registros das reuniões da primeira sprint
- **`Sprint02/`** - Links e registros das reuniões da segunda sprint
- **`SprintXX/`** - Links e registros das reuniões das demais sprints

## 📋 Conteúdo das Pastas

Cada pasta de sprint contém:

- **Links** para gravações das reuniões
- **Atas** e resumos dos principais pontos discutidos
