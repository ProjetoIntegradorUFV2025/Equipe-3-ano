# Pasta Dependências 

Esta pasta contém o gerenciamento das **dependências** necessárias para o desenvolvimento do projeto **(Des)conecta**. Aqui são organizados os recursos, bibliotecas e ferramentas externas utilizadas no projeto.

## 🗂️ Conteúdo da Pasta

- **Listagem** das dependências utilizadas
- **Versões** específicas de cada biblioteca
- **Configurações** de instalação e uso
- **Instruções** para atualização e manutenção
