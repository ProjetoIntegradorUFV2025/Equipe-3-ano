# Pasta Design - Materiais Visuais do Projeto

Esta pasta contém todos os **designs e materiais visuais** criados no **Figma** para o projeto **(Des)conecta**. Os arquivos estão organizados por sprints para facilitar o acompanhamento da evolução visual do projeto.

## 📁 Organização por Sprints

Os designs estão separados em pastas correspondentes a cada sprint do desenvolvimento:

- **`Sprint01/`** - Designs da primeira sprint
- **`Sprint02/`** - Designs da segunda sprint

## 🎯 Conteúdo das Pastas

Cada pasta de sprint pode conter:

- **Arquivos do Figma** (.fig) ou links para os projetos
- **Exports** das telas em diferentes formatos (PNG, JPG, SVG)
- **Assets** extraídos (ícones, ilustrações, componentes)
- **Documentação** das decisões de design da sprint
- **Protótipos** e wireframes desenvolvidos

## 💡 Como Utilizar

- **Desenvolvedores:** Consultem os designs para implementação das telas
- **Designers:** Mantenham os arquivos atualizados em suas respectivas sprints
- **Equipe geral:** Acompanhem a evolução visual do projeto
