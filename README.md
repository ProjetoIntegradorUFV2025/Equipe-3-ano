# 🎮 (Des)conecta - Repositório de Desenvolvimento

Este repositório contém todos os arquivos desenvolvidos durante a criação do jogo **(Des)conecta**, parte do **Projeto Integrador** desenvolvido pela equipe responsável pelo 3º ano. O jogo combina gamificação com o ensino de conceitos essenciais sobre dados e informação.

## 📁 Estrutura do Repositório

Este repositório documenta todo o processo de desenvolvimento do jogo, incluindo:

- Documentação de design e mecânicas
- Assets e recursos visuais
- Código fonte e scripts
- Testes e iterações do projeto
- Materiais educacionais complementares

## 📖 Sobre o (Des)conecta

O **(Des)conecta** é um jogo criativo no formato de história interativa com puzzles, onde o protagonista inicia uma aventura envolvente pelo mundo dos dados. Junto com o **Dadinho** - nosso mascote - os jogadores exploram, investigam e compreendem como dados se convertem em informação por meio de desafios de conexão ou caça-palavras, criando uma experiência divertida e educativa.

## ✨ Características Principais

### 📚 Narrativa Envolvente
Cada etapa do jogo apresenta uma história interessante que facilita o aprendizado sobre dados e informações.

### 🔍 Desafios de Caça-Palavras
Descubra dados específicos em caça-palavras temáticos que se conectam com as informações que precisam ser encontradas.

### 🔗 Desafios de Conexão
Una dados que se relacionam para criar informações completas através de atividades de associação e ligação.

## 🎲 Como Funciona?

Em cada etapa do jogo, os participantes experimentam uma narrativa única seguida por um desafio específico de conexão ou caça-palavras. Ao resolver cada atividade, eles coletam dados que, ao serem combinados, formam uma informação completa. Esta dinâmica ensina na prática a diferença entre dados separados e informação organizada.

## 🎯 Objetivos Educacionais

O jogo foi criado com objetivos pedagógicos bem definidos, buscando desenvolver habilidades importantes para o mundo digital. Por meio de uma abordagem divertida e participativa, os estudantes constroem uma compreensão consistente sobre conceitos básicos da computação:

### 🧠 Distinção de Conceitos
Ensinar a diferenciar com clareza dados (elementos separados) e informações (dados estruturados com significado).

### 🔗 Entendimento de Conexões
Mostrar como dados se conectam e se convertem em informação útil e com propósito.

### 🌍 Uso no Dia a Dia
Demonstrar que dados fazem parte da rotina de todas as pessoas, tornando o aprendizado mais próximo da realidade.
